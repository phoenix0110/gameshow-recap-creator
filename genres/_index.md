# 题材路由

本文件只负责为整条视频选择一个题材。选择后只加载对应文件；题材规范以该文件为唯一来源。

| 题材 | 指南 | 判断核心 |
|---|---|---|
| 旅行 | [travel.md](travel.md) | 路线和地点变化推动内容 |
| 美食 | [food.md](food.md) | 寻找、制作或品尝食物推动内容 |
| 生活 Vlog | [lifestyle-vlog.md](lifestyle-vlog.md) | 个人生活、关系或变化推动内容 |
| 科技 | [tech.md](tech.md) | 产品、技术、测试或使用判断推动内容 |
| 金融 | [finance.md](finance.md) | 钱、商业或经济决策推动内容 |
| 时政人文 | [current-affairs.md](current-affairs.md) | 事件、历史、社会或人物议题推动内容 |
| 电竞游戏 | [esports-gaming.md](esports-gaming.md) | 电子游戏对局、实况或攻略推动内容 |
| 综艺游戏 | [variety-game.md](variety-game.md) | 多人规则、回合或社交博弈推动内容 |

通读标题、元数据和完整字幕后，按全片的主要故事驱动力判断，不按单个关键词判断。混合内容也只选择对叙事影响最大的一个题材。

**无法归类时不要硬选**：如果证据不足以判断题材，**停下来问用户**，把上面的题材列表展示给用户，让用户指定最接近的一个。不要自行套用"通用方式"写脚本——不对口的题材模板产出的内容几乎不可用。

把结果写入 `pre-analysis.md`：

```markdown
## 题材路由
- 题材：旅行
- 判定依据：来自全片的具体素材证据
- 已加载：genres/travel.md
```
