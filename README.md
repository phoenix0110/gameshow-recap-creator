# Game Show 二创解说脚本生成器

把一整集海外 Game Show / Reality Show 压缩成 8–12 分钟的中文二创解说脚本。

## 核心能力

- **两层处理**：先做前置理解（角色表 + 游戏目标 + 主线 + 爆点），再生成脚本
- **场景适配**：完整节目精简 vs 剧集间衔接（起承转合）
- **人物标签化**：只给有戏份的人起口语化昵称，用"昵称 + 履历 + 判断"公式建档
- **早期押注**：第 2 分钟前引导观众选人押注，与原节目终极悬念对齐
- **属性定量化**：把"房子建得好"变成"3 天建了 2 层木屋，12 平米"
- **冲突放大**：对比、回调、量化、慢放、花字等手段强化 Drama Points
- **80% 压缩率**：50 分钟 → 10 分钟，只保留改变局势的动作

## 风格定位

第三方解说视角，俏皮且有激情，每句话同时承担信息和情绪。
不是翻译原片，是二次编剧。

## 禁止

- 照搬任何特定 UP 主的口头禅/系列名/昵称格式
- 逐句翻译原片旁白
- 开头做慢节奏铺垫
- 只在结尾问观众问题
- 人身攻击

## 使用

把整集字幕/ASR 喂给模型，调用本 Skill，先输出第一层分析文档，
确认后再生成第二层完整脚本。

## 文件

- `SKILL.md` — 完整 Skill 文档（含两层架构、场景 A/B、风格规范、输出格式、自检清单）
